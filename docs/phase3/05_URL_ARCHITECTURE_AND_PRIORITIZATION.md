## 3. QUALITY CRITERIA & ANTI-THIN-CONTENT MANDATE

In strict compliance with Workstream 2 & 5 requirements:
- **No Templatized Carbon Copies:** Every page features unique, domain-specific pain points, authentic customer workflow scripts with realistic conversational dialogues, customized integration rosters, and tailored FAQ sets.
- **Answer Engine Optimization:** Every page incorporates a prominent `<KeyTakeaway>` summary paragraph engineered for direct AI quote extraction.
- **Structured Schema Markup:** Each page automatically outputs `Service`, `FAQPage`, and `BreadcrumbList` JSON-LD schemas matching visible on-page content.
- **Transparent Honest Limitations:** Every industry page explicitly states what StarX-Flow is NOT built for (e.g., Dental page clarifies that StarX-Flow does not replace Dentrix EHR; Restaurant page clarifies that it does not replace OpenTable seating grids).
